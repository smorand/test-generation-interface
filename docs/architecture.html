Comment installer

Deux prerequis, un fichier de configuration, une commande. Dix minutes, tout au terminal.

1Prerequis
Installer uv et git. uv gere Python 3.13, rien d'autre a installer.
2Cloner le depot
git clone <url> puis cd test-generation-interface
3Installer les dependances
uv sync
4Configurer .env
Copier .env.example, renseigner l'URL du LLM, la cle d'API, les deux modeles (generateur et juge). Selon l'infra: TGI_DISABLE_THINKING, le TLS (CA_BUNDLE ou VERIFY_SSL), puis TGI_LOGS et TGI_PROJECTS_DIR vers des dossiers locaux.
5Lancer
uv run tgi — ou le raccourci tgi.bat (Windows), ./tgi.sh (macOS, Linux)
6Ouvrir l'interface
Navigateur sur http://localhost:8080
Verifier avant de lancer
uv run tgi-validate traite un document d'exemple et affiche VERDICT: USABLE si l'endpoint repond.

Pipeline par bloc

Chaque passe du juge est une version scoree. La meilleure gagne, jamais la derniere. Des controles filtrent les tests a chaque passe.

Blocsection du document
Extracteur1 appel
Generateur1 appel / 8 regles
Juge1 appel / 10 regles
Regenerationregles non couvertes
Terminescore ≥ seuil
Seuil jamais atteint: la meilleure version scoree est restauree, le bloc passe en revue humaine
score ≥ seuil
score < seuil
nouvelle passe
3 passes
Controles a chaque passe
Juge score la couverture localement (regles couvertes / evaluees, par lots de 10). Les quasi doublons sont ecartes, chaque regle est plafonnee a 4 tests, une regle saturee sort du brief de regeneration. Le juge ne leve jamais: sans verdict, les tests sont gardes et un humain tranche.
